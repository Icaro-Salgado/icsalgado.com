About

Hi, I'm Ícaro, a software engineer based in São Paulo, Brazil.

I'm a nerd. I like taking things apart to see how they work and chewing on a problem until it makes sense. That didn't change when it became my job.

I started programming through games, tinkering with mods and servers (anyone else remember the Habbo retro servers?). Then I set it aside for a while to study Materials Engineering, until joining the Computer Society pulled me back in. The data internship that came next made it clear this was where I wanted to stay. Today I work on backend at Mercado Libre.

I plan to use this space to write down what I learn along the way. I mostly write for myself, but if something here helps you, even better.

Away from the keyboard: the gym, and a bit of gaming so I don't lose the habit.
